## מה יש בפרויקט

- קובץ הגלם `Titanic.csv` — 891 נוסעים ו-12 עמודות.
- סקריפט `analysis.py` — טעינה, הנדסת מאפיינים בסיסית, סיכומים סטטיסטיים ושמירת גרפים.
- תיקיית `figures/` — תרשימים שנוצרים בהרצה.
- `requirements.txt` — ספריות Python נדרשות.

הסקריפט לא מאמן מודל חיזוי. הוא מתמקד בחקירה תיאורית (EDA): שיעורי הישרדות לפי מין, מחלקה, גיל, משפחה, מחיר כרטיס, נמל עלייה ותואר בשם.

## מבנה הפרויקט

```
titanicANALYSIS/
├── Titanic.csv          # נתוני הגלם
├── analysis.py          # ניתוח + יצירת גרפים
├── requirements.txt     # תלויות
├── figures/             # תמונות שנוצרות בהרצה
└── README.md
```

## התקנה והרצה

מומלץ סביבה וירטואלית, ואז:

```bash
pip install -r requirements.txt
python analysis.py
```

ההרצה מדפיסה טבלאות סיכום לטרמינל ושומרת גרפים תחת `figures/`.

## תיאור הנתונים

הקובץ הוא סט האימון המוכר מתחרות Kaggle *Titanic: Machine Learning from Disaster*. כל שורה היא נוסע אחד. משתנה המטרה הוא `Survived` (1 = שרד, 0 = נספה).

| מדד | ערך |
|-----|-----|
| מספר נוסעים | 891 |
| שרדו | 342 (38.4%) |
| נספו | 549 (61.6%) |
| נשים | 314 |
| גברים | 577 |
| מחלקה 1 / 2 / 3 | 216 / 184 / 491 |

ערכים חסרים:

| עמודה | חסרים | אחוז |
|-------|--------|------|
| Age | 177 | 19.9% |
| Cabin | 687 | 77.1% |
| Embarked | 2 | 0.2% |

`Cabin` חסר ברוב השורות, ולכן בשימוש בעיקר כאינדיקטור "יש מספר תא / אין". `Age` חסר בעיקר במחלקה 3. שני ערכי `Embarked` החסרים הם נשים במחלקה 1 ששרדו.

## עמודות ומשמעותן

| עמודה | תיאור |
|-------|--------|
| PassengerId | מזהה ייחודי לנוסע |
| Survived | 0 = נספה, 1 = שרד |
| Pclass | מחלקת כרטיס: 1 גבוהה, 2 בינונית, 3 נמוכה |
| Name | שם מלא, כולל תואר (Mr, Mrs, Miss, Master וכו') |
| Sex | מין |
| Age | גיל בשנים; חלקי לשנים לתינוקות |
| SibSp | מספר אחים/אחיות ובני/בנות זוג על הסיפון |
| Parch | מספר הורים או ילדים על הסיפון |
| Ticket | מספר כרטיס (לפעמים משותף לקבוצה) |
| Fare | מחיר הכרטיס בליש"ט |
| Cabin | מספר תא; חסר ברוב הנוסעים |
| Embarked | נמל עלייה: C = Cherbourg, Q = Queenstown, S = Southampton |

מאפיינים שהסקריפט גוזר:

| מאפיין | חישוב |
|--------|--------|
| Title | תואר מתוך השם |
| FamilySize | `SibSp + Parch + 1` (כולל הנוסע) |
| IsAlone | 1 אם FamilySize = 1 |
| HasCabin | 1 אם יש ערך ב-Cabin |
| AgeGroup | קבוצות גיל: 0–12, 13–18, 19–35, 36–50, 51+ |
| FareQuartile | רבעוני מחיר כרטיס |

## שאלות המחקר

1. האם מין הנוסע השפיע על סיכויי ההישרדות?
2. מה הקשר בין מחלקת הכרטיס להישרדות?
3. כיצד הגיל משפיע על ההישרדות?
4. האם נסיעה עם משפחה שיפרה את הסיכויים?
5. האם מחיר הכרטיס ונמל העלייה קשורים להישרדות?

## תהליך הניתוח

1. טעינת `Titanic.csv` עם pandas.
2. בדיקת גודל, טיפוסים וערכים חסרים.
3. חישוב שיעור הישרדות כולל וחתכים לפי מין, מחלקה, שילוב מין×מחלקה, גיל, גודל משפחה, נמל ומחיר.
4. חילוץ תואר מהשם כפרוקסי למין, מצב משפחתי וגיל (למשל Master לילדים).
5. שמירת גרפי עמודות, היסטוגרמת גיל ומפת מתאמים.

אין מילוי אוטומטי של גיל חסר בגרפים לפי קבוצת גיל — שיעורי הגיל מחושבים רק על 714 נוסעים עם גיל ידוע.

## ממצאים עיקריים

**מין.** נשים שרדו ב-74.2% (233 מתוך 314). גברים שרדו ב-18.9% (109 מתוך 577). הפער תואם את מדיניות "נשים וילדים קודם" בסירות ההצלה.

**מחלקה.** מחלקה 1: 63.0%. מחלקה 2: 47.3%. מחלקה 3: 24.2%. ככל שהמחלקה נמוכה יותר, שיעור ההישרדות יורד.

**מין × מחלקה.** זה החתך החזק ביותר בנתונים:

| מחלקה | נשים | גברים |
|--------|------|--------|
| 1 | 96.8% | 36.9% |
| 2 | 92.1% | 15.7% |
| 3 | 50.0% | 13.5% |

כמעט כל הנשים במחלקות 1 ו-2 שרדו. גברים במחלקות 2 ו-3 שרדו בשיעורים נמוכים מאוד.

**גיל.** גיל חציוני 28, ממוצע 29.7 (טווח 0.42–80). ילדים עד גיל 12: 58.0% הישרדות (n=69). בני 51+: 34.4%. צעירים בני 19–35, הקבוצה הגדולה ביותר, שרדו ב-38.3% — קרוב לממוצע הכללי.

**משפחה.** נוסעים לבד: 30.4% הישרדות (n=537). משפחות קטנות (2–4 אנשים) שרדו ב-55%–72%. משפחות גדולות (5+) שרדו הרבה פחות; בקבוצות של 8 ו-11 איש אף אחד לא שרד במדגם. משפחה קטנה עזרה; משפחה גדולה במחלקה 3 הייתה קשורה לסיכון גבוה.

**מחיר כרטיס.** ממוצע מחיר למי ששרד: 48.40. למי שנספה: 22.12. ברבעון הזול ביותר שרדו 19.7%; ביקר ביותר 58.1%. המחיר חופף חזק למחלקה.

**נמל עלייה.** Cherbourg (C): 55.4%. Queenstown (Q): 39.0%. Southampton (S): 33.7%. Cherbourg כלל שיעור גבוה יותר של נוסעי מחלקה 1, כך שהפער אינו בהכרח "השפעת הנמל" לבדה.

**תא.** לנוסעים עם מספר תא ידוע שיעור הישרדות 66.7%, בלי תא 30.0%. גם זה בעיקר פרוקסי למחלקה 1 (שם נרשמו תאים יותר).

**תואר בשם.** Mr: 15.7% (n=517). Mrs: 79.2%. Miss: 69.8%. Master (ילדים): 57.5%. Rev: 0% (6 אנשי דת). התואר מסכם מין, גיל ומעמד חברתי בשדה אחד.

**מתאם מספרי.** `Pclass` מתואם שלילית עם הישרדות (מחלקה גבוהה יותר מקודדת כמספר נמוך יותר ולכן הקורלציה עם `Survived` חיובית ל-Fare ושלילית ל-Pclass). `Fare` מתואם חיובית עם הישרדות. `Age` מתואם חלש-שלילי.
